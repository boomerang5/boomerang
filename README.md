# Boomerang

Video-call platform with real-time speech translation: each participant speaks their own language and hears the other in theirs, through a pipeline combining speech-to-text, translation, and text-to-speech across Spanish, English, Italian, Portuguese, Chinese, and more.

Built like Zoom or Google Meet on WebRTC and WebSockets. Also features an "air whiteboard" — a hand-tracking system where pinching thumb and index finger acts as a click, letting you draw mid-air without touching anything.

## Features
- Real-time speech-to-speech translation across multiple languages
- Video calls over WebRTC with WebSocket signaling
- Hand-tracking "air whiteboard" for mid-air drawing
- Individual and group chat, contacts, and profiles
- Shared calendar
- AI chatbot (Groq) that answers questions about a call using its transcript as context
